# Template: detailed table (standard)

The default table style. Dark card, navy header with a thick blue rule, banded rows, a free-text column with
cyan code chips inside the sentences, and a rounded status pill per row. Icons in the first column when they fit.

Use for runbooks, pipeline stages, release notes, change plans: any table where each row needs a sentence or two.

Plain Markdown fallback (for GitHub, which strips the styling):

| Stage | What happens | Status |
|---|---|---|
| Validate | Runs `terraform fmt -check` and `terraform validate`, then scans with `tflint` and `checkov`. Any finding stops the run. | Passed |
| DEV | Plans against the dev state file and applies the saved `tfplan-dev` straight away. No approval. | Deployed |
| UAT | Plans, then waits for a named approver. Applies the saved `tfplan-uat` once approved. | Waiting |
| PROD | Needs approval and runs only between 08:00 and 16:00 CET on weekdays. | Blocked |
