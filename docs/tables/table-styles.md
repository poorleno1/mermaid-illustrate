rule), body from styles 3 and 6 (dark card, banded rows), cyan names from style 6, rounded chips from style 4 and
rounded status pills from style 6. Icons where they fit; optional.

Each table is an HTML block with inline styles, because Markdown tables have no styling syntax. GitHub strips
`style` attributes and shows a plain table; the Azure DevOps wiki allows HTML (not yet tested with these).

Writing rules: no blank lines inside the `<table>` block, no indentation of four spaces or more, and use
`<code>`, `<b>` and `<br>` inside cells, because Markdown syntax is not processed there.
